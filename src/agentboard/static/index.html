Get started

A live board for the AI agents you run side by side. They report their own progress here; you watch, answer their questions and sign off what they finish.

  1. 1Add a task: or press n
  2. 2Connect an agent: in your project run agentboard instructions and paste what it prints into the project's CLAUDE.md or AGENTS.md
  3. 3Watch it move: a task goes from Todo to Doing when an agent starts it, and to Done when you sign it off

Just looking around? or press ? for the keyboard shortcuts.

Optional: let one Claude session coordinate the board (ORCH)

ORCH is a Claude session that runs this board for you: it adds tasks, hands them to agents and answers you in the ORCH drawer. In Claude Code:

  1. 1Open a terminal and start Claude: claude
  2. 2In it, type /rename ORCH
  3. 3Press and paste it there
