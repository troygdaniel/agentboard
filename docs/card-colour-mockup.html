Why colour does not help today

Today AGENT-1 to AGENT-5: one colour for five agents
Proposed one hue each, none of them orange, green or red (those belong to status)

Colour is set on each card when it is claimed, so an agent's cards drift: AGENT-1 has 113 cards as "green", 81 as "#22c55e" and 7 with none, and this card shows grey. Green is also the colour of "ready for review", so a green agent looks like a review card.

The scheme: one channel per fact

Agent → the name chip and left rail

One colour per agent name, set once, inherited by every card it holds. Agents stop choosing colours; you change it by clicking the avatar.

As today: orange running, green review, red needs you, grey done. Nothing else may use these three hues.
