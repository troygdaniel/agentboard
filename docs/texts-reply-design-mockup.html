Settings → Texts: every state

The first sheet shows the explanatory lines in full; the rest drop them to stay readable. The new row is Text me back, under "Pull my texts every minute", built on the same Off / Subtle / Full control the sheet already uses. Send never arms on one click: it asks first (third sheet).

Header chip

No second chip: the Texts chip that shows the last pull gains the reply state after a dot. Narrow screens (resize this window under 600px) keep the dot only: hollow ring = dry run, solid green = sending, amber = paused or stopped.

Try it

Click the control. Send asks first; Escape or Not now cancels. This sheet shares its render function with the ones above, and nothing here sends anything.
